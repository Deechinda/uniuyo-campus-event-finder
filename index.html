The Project

About UNIUYO Campus Event Finder

🎓 Academic Prototype – Front-End Development Project

UNIUYO Campus Event Finder is a student academic project developed as part of a front-end web development course at the University of Uyo. The project was designed and implemented using HTML5, CSS3, and Vanilla JavaScript.

The website demonstrates a centralized platform where students could discover, organize, and explore campus-related events across the three university campuses: Permanent Site, Town Campus, and Annex.

Important: This is a demonstration prototype only. All events listed on this website are fictional sample data created for academic purposes. The website has no backend server, no database, and is not officially affiliated with University of Uyo management. Registrations and submitted events are stored only in the current browser.

Event data and registrations are stored in browser localStorage. This data is not shared between devices and can be cleared by the user at any time.
